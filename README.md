# Ciphera Homebrew tap

```bash
brew install ciphera-net/tap/pulse
```

| Formula | Description |
|---|---|
| [`pulse`](Formula/pulse.rb) | [Pulse CLI](https://github.com/ciphera-net/pulse-cli) — read your Pulse analytics from the terminal |

Formulae here are generated by [goreleaser](https://goreleaser.com) when a release is tagged in the
source repository. **Edit the release configuration, not the formula** — a hand-edit is overwritten by
the next release, and the discrepancy is invisible until someone's `brew upgrade` reverts it.

> The tap is `ciphera-net/tap`, not `ciphera/tap`. Homebrew resolves `user/tap` to
> `github.com/user/homebrew-tap`, and `ciphera` on GitHub is an unrelated account.
